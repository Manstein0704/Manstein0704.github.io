# Manstein0704.github.io

Personal technical blog and portfolio built with GitHub Pages and Jekyll.

## Add a post

Create a Markdown file under `_posts/` using:

```text
YYYY-MM-DD-title.md
```

Example front matter:

```yaml
---
layout: post
title: "Post title"
date: 2026-09-16
categories: [learning]
tags: [python, dp]
---
```
